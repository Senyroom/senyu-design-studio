# 前台交互对照

| 区域 | 目标站观察 | 本地实现与检查 |
|---|---|---|
| 身份标签 | 上方两行排列，进入视野后散落，碰撞堆积于面板底部；可拖动 | 对齐面板、标签尺寸、胶囊轮廓和职业／身份／学历三种样式；已观察实际下落并验证拖动。按用户要求移除可见拖动提示 |
| 文件夹 | 点击展开／收起，标签随封面翻折，小卡片横向展开；彩色磨砂封面能看到后方卡片的模糊轮廓 | 三个模块均对齐彩色磨砂渐变、按尺寸缩放的模糊、缺口封面、封面文案、卡片配色与排版；已操作三个文件夹开合及点击外部收起 |
| 页面滚动 | 桌面介绍、文章、课程层叠在导航下方，贴近顶部时顶角变直 | Sticky 面板与圆角联动；修正向前跳转锚点的位置；手机使用普通文档流 |
| 文章 | 文件夹／列表切换，分类筛选，右侧文章星球 | 球面投影、分类颜色、连线、拖动与惯性、悬停减速，列表节点高亮联动；11 项分类筛选与真实拖动已验证 |
| 课程 | 进入视野自动逐字打印，纸张升起；按钮定位课程 | 自动逐字出纸、纸张升起、击杆与按键动作；已观察打印完成。按钮定位并重播 |
| 手机课程 | 显示完整可阅读介绍，使用静态机器图 | 窄屏提供正文与静态图；375px 无横向溢出 |
| 名片 | 吊绳物理摆动，拖动，点击翻面；微信按钮显示二维码 | 保留物理拖动与翻面，增加键盘翻面和左右摆动；二维码已验证 |
| 社交与人物 | 四个媒体入口、女生人物 | 按用户要求改为三个入口，移除推特并放大图标；使用用户男生图片替换首屏、头像和挂卡 |
| 页底 | 联系区结束 | 按用户要求移除另加的页底品牌、标语和返回顶部导航栏 |


鼠标流体：已对照参考站改为首屏内的彩虹背景流体，使用容器范围输入检测、独立层叠与边界裁切；文章、课程、联系等其他模块不显示全屏拖尾。

顶部导航：对照参考站使用固定玻璃层，白色 50% 透明背景、20px 模糊、1.4 饱和度和半透明底边线。首屏画布从页面顶部开始，彩色流体可透过导航显示；首屏内容使用导航高度内边距保持位置，画布仍限定于首屏。已在内置浏览器观察导航后方的磨砂彩色效果，并检查文章、课程锚点与 375px 窄屏布局。
